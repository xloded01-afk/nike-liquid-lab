# Nike Liquid Lab

Интерактивное раскрытие материалов логотипа через GPU-симуляцию жидкости.
Мышь без нажатия выбрасывает поток вперёд. Он продолжает движение, закручивается,
образует перемычки и отделяющиеся участки, затем исчезает.

## Запуск

Откройте **Liquid Lab.html** двойным щелчком в современном браузере.
Весь код, изображения и шрифты встроены; интернет и установка пакетов не нужны.

Для разработки из каталога проекта:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/dist/index.html. Модульную версию из `dist` нужно
открывать через HTTP, автономный `Liquid Lab.html` можно открывать как файл.

Движение включено по умолчанию независимо от системной настройки уменьшения движения.
Кнопка **«Движение: вкл.»** позволяет отключить его вручную.
**«Показать слой»** открывает материал целиком, в том числе с клавиатуры.
На сенсорном экране проводите пальцем по области логотипа; вне этой области
сохраняется прокрутка. «Хром», «Пузыри», «Пена», «Авто», «Сбросить» управляют эффектом.

## Устройство

WebGL 2 / GLSL ES 3.0 без зависимостей. Three.js не требуется: движок непосредственно
работает с framebuffer и текстурами RGBA16F.

- Скорость определяется по координатам и времени событий, включая coalesced events.
- Непрерывное направленное сопло вносит плотность и импульс. Ширина, изгиб и длина
  выброса зависят от скорости и поворота указателя.
- Поле скорости: адвекция, vorticity confinement, divergence, 18 итераций давления
  Jacobi, вычитание градиента давления.
- Плотность: ограниченная коррекция MacCormack, неодинаковое пространственное
  затухание и эрозия. Маска хранится и переносится на GPU, не рисуется кругами.
- Smooth threshold и производные сглаживают контур. Потоки объединяются в общем
  поле; тонкие перемычки распадаются при переносе и затухании.
- Оба слоя используют один прямоугольник и alpha-канал логотипа. Маска раскрывает
  весь первый экран, включая фон; текст меняет контраст внутри раскрытия.
- Независимые разрешения скорости, маски и экрана. DPR до 2. После исчезновения
  следа и в скрытой вкладке лишние кадры прекращаются.

Это художественная двумерная модель потока, не трёхмерный расчёт поверхности воды.
Материалы рассчитаны по картам нормалей, без полигональной 3D-модели логотипа.
Без WebGL 2 / float framebuffer доступен статический просмотр с понятным сообщением.
Canvas-кисть не подменяет жидкую симуляцию. Старый `cpu-fluid.js` не используется.

## Файлы

- `dist/app.js`: GPU-движок, шейдеры, композитинг, интерфейс.
- `dist/jet-input.js`: движение и остаточное давление сопла.
- `dist/index.html`, `dist/styles.css`: адаптивная страница.
- `dist/assets/`: локальные изображения, карты нормалей, шрифты.
- `scripts/build-standalone.py`: пересборка автономного HTML, стандартный Python.
- `scripts/jet-input.test.mjs`: тесты ввода.
- `gpu-check.html`: браузерные GPU-тесты (через HTTP); `?mode=shape` сохраняет
  кадр потока, `?mode=bench` измеряет частоту кадров.

Настройки в `CONFIG` в начале `dist/app.js`:

| Параметр | Значение | Назначение |
| --- | --- | --- |
| nozzleRadius | 0.043 | Базовая ширина относительно высоты экрана |
| jetSpeed | 1.75 | Множитель скорости выброса |
| decay | 0.95 | Затухание плотности в секунду |
| swirl | 13 | Сила завихрений |
| velocityDecay | 1.15 | Затухание импульса |
| simulationResolution | 240 | Короткая сторона поля скорости |
| dyeResolution | 640 | Короткая сторона маски; на телефоне 400 |
| pressureIterations | 18 | Итерации давления |
| maxPixelRatio | 2 | Ограничение DPR |

После изменений: `python scripts/build-standalone.py`.
Тесты ввода: `node --test scripts/jet-input.test.mjs`.
Скрипты подготовки изображений требуют Pillow / NumPy; исходная подготовка также
требует SciPy и указанного в скрипте шрифта. Для обычного запуска они не нужны.

## Проверки от 2 ноября 2026

4 теста ввода: PASS. Проверены частота событий, остаточный выброс, направление
поворота, повторный вход и ограничение очереди.

В браузере проверен основной **WebGL 2**: шейдеры компилируются, поля конечны,
ошибок GPU нет. Тесты при 390 и 768 px подтверждают hover без нажатия, опережение
курсора, инерцию и полное исчезновение маски. Композиция просмотрена при 1440 px.

При viewport 1440×900, canvas 1425×900 (DPR 1) медианный интервал кадров 4.2 мс,
p95 4.3 мс, средняя частота около 238 FPS. Это результат конкретного тестового
окружения, не гарантия для любого GPU и DPR.

Style-inspector не запустился из-за ошибки Chrome/crashpad; адаптивность проверена
во встроенном браузере. Lint: 0 FAIL, 2 WARN о сохранённых подписях и тире.
Отдельного видео во вложении не было; использованы текстовое ТЗ и сайт-референс.
